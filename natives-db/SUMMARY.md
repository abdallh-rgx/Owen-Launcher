## الملفات
- `natives-vX.YY.json` — كل دالة: `{name: {thunk: 0x.., orig: 0x..}}`
- `by-name.json` — فهرس عكسي: لكل اسم → كل النسخ وعناوينها
- `version-diffs.json` — الفروق بين كل نسختين متتاليتين (دوال مضافة/محذوفة)
- `erbium-native-map.json` — ربط دوال Erbium بمقابلاتها الـ native

## ملاحظات تقنية
- `thunk` = دالة exec الـ UFunction (نقطة هوك ExecHook المثالية — تعمل حتى لو كان الـ impl مطوي ICF)
- `orig` = التنفيذ الأصلي عندما يكون مستقلاً (0 = مفقود/مطوي ICF/متطابق مع الـ thunk)
